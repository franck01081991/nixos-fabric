# Tests for NixOS Fabric

This directory contains tests for validating the NixOS Fabric configurations.

## Test Structure

```
tests/
├── wireguard-config-test.nix      # WireGuard configuration test
├── frr-config-test.nix            # FRR configuration test
├── wireguard-wg0-test.nix         # WireGuard wg0.conf configuration test
├── wireguard-secrets-test.nix     # WireGuard secrets configuration test
├── run-tests.sh                   # Main test runner script
└── ... (other existing tests)
```

## Running Tests

### Quick Tests

Run only the new configuration tests:

```bash
./tests/run-tests.sh --quick
```

### Full Tests

Run all tests including the new configuration tests:

```bash
./tests/run-tests.sh
```

## Test Descriptions

### WireGuard Configuration Test

- **File**: `wireguard-config-test.nix`
- **Description**: Validates the WireGuard configuration generated by the `wireguard.nix.j2` template.
- **Variables Tested**: `wg_ip_address`, `wg_peers`, etc.

### FRR Configuration Test

- **File**: `frr-config-test.nix`
- **Description**: Validates the FRR configuration generated by the `frr.nix.j2` template.
- **Variables Tested**: `bgp_as`, `bgp_router_id`, `bgp_neighbors`, etc.

### WireGuard wg0.conf Configuration Test

- **File**: `wireguard-wg0-test.nix`
- **Description**: Validates the WireGuard wg0.conf configuration generated by the `wg0.conf.j2` template.
- **Variables Tested**: `wireguard_address`, `wireguard_port`, `wireguard_peers`, etc.

### WireGuard Secrets Configuration Test

- **File**: `wireguard-secrets-test.nix`
- **Description**: Validates the WireGuard secrets configuration generated by the `wireguard-secrets.j2` template.
- **Variables Tested**: `wg_public_key.stdout`, `wireguard_endpoint`, `wireguard_peers`, etc.

## Adding New Tests

To add a new test:

1. Create a new test file in the `tests/` directory with the `.nix` extension.
2. Use the `nix-instantiate` command to evaluate the test.
3. Add the test to the `run-tests.sh` script.

Example test file:

```nix
{ pkgs, ... }:

let
  # Import the module to test
  config = import ./path/to/module.nix {
    variable1 = "value1";
    variable2 = "value2";
  };
in
{
  config = config;
  isValid = config.someAttribute != null;
}
```

## Test Execution

The `run-tests.sh` script provides a convenient way to run all tests and see the results. It supports the following options:

- `--quick`: Run only the quick tests.
- `--verbose`: Show verbose output for each test.

## Test Results

The test results are displayed in a summary at the end of the test run, showing the total number of tests, passed tests, and failed tests.

## Continuous Integration

The tests are integrated into the CI/CD pipeline to ensure that all configurations are validated automatically. See the `.github/workflows/ci-cd-pipeline.yml` file for details.
