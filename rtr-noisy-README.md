# rtr-noisy Configuration - Hybrid Node

**NixOS Fabric Infrastructure - Hybrid Spine/Leaf Router Configuration**

## 🎯 Node Overview

**rtr-noisy** is a **hybrid node** in the network fabric architecture:

- **Role**: Simultaneous spine AND leaf functionality
- **Protocols**: OSPF + BGP (spine) + BGP + EVPN (leaf)
- **Topology**: Dual-role connectivity
- **Function**: Core routing + edge services

## 📂 Configuration Structure

```
rtr-noisy-config/
├── hardware-configuration.nix  # Hardware-specific settings (generated)
├── base-variables.nix         # Base configuration overrides
├── role-variables.nix          # BOTH spine AND leaf role variables
├── variables.nix              # Comprehensive configuration
└── default.nix                # Host-specific tweaks (15-20 lines)
```

## 🔧 Configuration Files

### `hardware-configuration.nix`
- **Generated by**: `nixos-generate-config`
- **Contains**: Hardware-specific settings (disks, filesystems, boot)
- **Do not edit manually** unless necessary

### `base-variables.nix`
- **Purpose**: Base system configuration overrides
- **Content**: Users, packages, system services, time zone

### `role-variables.nix`
- **Purpose**: Hybrid role-specific configuration
- **Content**: OSPF, BGP (spine) + BGP, EVPN (leaf)
- **Unique**: Contains BOTH spine and leaf role definitions

### `variables.nix`
- **Purpose**: Comprehensive configuration variables
- **Content**: Network interfaces, WireGuard, FRR, security

### `default.nix`
- **Purpose**: Minimal host-specific configuration
- **Content**: Host-specific tweaks (15-20 lines max)

## 🚀 Usage

### With NixOS Fabric Main Repository

This repository is designed to be used as a **Git submodule** in the main [nixos-fabric](https://github.com/franck01081991/nixos-fabric) repository.

### Standalone Usage

You can also use this configuration independently.

## 🔄 Update Process

```bash
# Make changes to configuration files
nano variables.nix

# Test locally
nix eval .#nixosConfigurations.rtr-noisy.config.networking.hostName

# Commit and push
git add .
git commit -m "Update rtr-noisy configuration"
git push origin main
```

## 🛡️ Security

- WireGuard keys should be generated per-host
- BGP neighbors should use MD5 authentication
- SSH access should be restricted
