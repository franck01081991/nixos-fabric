# Ansible Integration Guide

This guide explains how Ansible is integrated with the NixOS fabric infrastructure.

## Overview

Ansible is used alongside NixOS to provide:

1. **Idempotent operations** - Tasks that need to be run multiple times
2. **Provisioning** - Initial setup of new nodes
3. **Configuration management** - Managing state that's difficult with Nix
4. **Verification** - Checking the status of the fabric

## Architecture

```
NixOS Fabric with Ansible
├── NixOS (Primary Configuration)
│   ├── Declarative configuration
│   ├── System packages
│   ├── Service definitions
│   └── Immutable infrastructure
│
└── Ansible (Complementary Management)
    ├── Idempotent tasks
    ├── Dynamic configuration
    ├── State management
    ├── Verification
    └── Provisioning
```

## Integration Points

### 1. Nix Module Integration

Ansible is now integrated as a Nix module (`modules/ansible.nix`) that:

- Installs Ansible automatically via Nix
- Generates configuration files during system activation
- Creates proper directory structure
- Manages host and group variables

### 2. Inventory Generation

Ansible inventory is automatically generated from NixOS host configurations during system activation:

```bash
# The inventory is generated automatically when you deploy with Nix
sudo nixos-rebuild switch --flake .#rtr-sapinet
```

### 3. Role Mapping

| NixOS Role | Ansible Group | Nix Configuration |
|------------|---------------|-------------------|
| Spine      | `spine`       | `role-variables.nix` |
| Leaf       | `leaf`        | `role-variables.nix` |
| Hybrid     | `hybrid`      | `role-variables.nix` |

### 4. Deployment Workflow

```bash
# Traditional NixOS deployment (still works)
sudo nixos-rebuild switch --flake .#rtr-sapinet

# Nix-integrated Ansible deployment (recommended)
./scripts/deploy-ansible-nix.sh rtr-sapinet

# Manual Ansible deployment (for debugging)
./scripts/deploy-with-ansible.sh rtr-sapinet
```

## Recommended Workflow

### 1. Nix-Integrated Deployment (Recommended)

```bash
# Deploy with full Nix+Ansible integration
./scripts/deploy-ansible-nix.sh rtr-sapinet

# This will:
# 1. Build NixOS configuration with Ansible module
# 2. Install Ansible via Nix
# 3. Generate Ansible configuration and inventory
# 4. Run Ansible playbooks
```

### 2. Traditional NixOS Deployment (Still Works)

```bash
# Deploy without Ansible (Ansible won't be installed)
sudo nixos-rebuild switch --flake .#rtr-sapinet
```

### 3. Manual Ansible Deployment (For Debugging)

```bash
# Generate inventory manually
./scripts/generate-ansible-inventory.sh

# Test connectivity
ansible all -m ping

# Run playbooks manually
ansible-playbook ansible/playbooks/main.yml
```

## Usage Examples

### Basic Commands

```bash
# Test connectivity (using Nix-generated config)
ansible all -m ping --inventory /etc/nixos-fabric/ansible/inventory/hosts.ini

# Run main playbook
ansible-playbook /etc/nixos-fabric/ansible/playbooks/main.yml

# Run verification
ansible-playbook /etc/nixos-fabric/ansible/playbooks/verify-fabric.yml

# Target specific host
ansible-playbook /etc/nixos-fabric/ansible/playbooks/main.yml --limit rtr-sapinet
```

### Common Tasks

```bash
# Deploy WireGuard
ansible-playbook ansible/playbooks/main.yml --tags wireguard

# Verify fabric status
ansible-playbook ansible/playbooks/verify-fabric.yml

# Check routing
ansible all -a "vtysh -c 'show ip bgp summary'"
```

## Nix Configuration Structure

The Ansible integration is configured through Nix modules:

```
modules/
└── ansible.nix          # Main Ansible Nix module

hosts/
└── default-ansible.nix  # Default Ansible configuration for all hosts
```

### Nix Module Options

The `ansible.nix` module provides these configuration options:

```nix
network-fabric.ansible = {
  enable = true;  # Enable Ansible integration
  
  version = "core-2.15";  # Ansible version
  
  generateInventory = true;  # Auto-generate inventory
  
  playbooks = [ "main.yml" "verify-fabric.yml" ];  # Available playbooks
  
  configOptions = {  # Ansible configuration
    defaults = { inventory = "/etc/nixos-fabric/ansible/inventory/hosts.ini"; };
    # ... other Ansible config options
  };
  
  hostVars = {  # Host-specific variables
    "rtr-sapinet" = { wireguard_address = "10.255.0.1/24"; };
    "rtr-noisy" = { wireguard_address = "10.255.0.11/24"; };
  };
  
  groupVars = {  # Group-specific variables
    "spine" = { frr_bgp_as_number = 65000; };
    "leaf" = { frr_bgp_as_number = 65000; };
  };
};
```

## Advanced Usage

Create host-specific variables in `ansible/host_vars/`:

```yaml
# ansible/host_vars/rtr-sapinet.yml
wireguard_address: "10.255.0.1/24"
wireguard_endpoint: "45.90.162.251"
peer_public_key: "BASE64_PUBLIC_KEY"
```

### Role Development

To add a new Ansible role:

```bash
ansible-galaxy init ansible/roles/new-role
```

Then integrate it into the main playbook.

## Troubleshooting

### Common Issues

1. **Python interpreter not found**
   - Ensure `ansible_python_interpreter` is set correctly
   - Use `/run/current-system/sw/bin/python3` for NixOS

2. **Permission denied**
   - Check SSH keys and sudo configuration
   - Verify Ansible user has proper permissions

3. **Module not found**
   - Install required Ansible collections
   - Check Python dependencies

### Debugging

```bash
# Verbose output
ansible-playbook main.yml -vvv

# Check specific host
ansible rtr-sapinet -m setup

# Test connectivity
ansible all -m ping
```
